# Temas Selectos de Físca Computacional
## Ambiente de Trabajo 
El siguiente repositorio tiene el propósito de mostrar el proceso de creación del ambiente de trabajo que se utilizara a lo largo del curso de Temas Selectos de Fisica Computacional. 
Se muestra la instalación para Windows 11, permitiendo que posteriores usuarios puedan replicar el procedimiento utilizado y obtener los mismos resultados.
